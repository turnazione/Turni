==================================================
  I MIEI TURNI v4.0 - PWA Web App per GitHub Pages
==================================================

Istruzioni per l'aggiornamento del Repository GitHub:

1. Sostituisci il contenuto di 'index.html', 'manifest.json' e 'service-worker.js' sul tuo repository GitHub Pages ("miei-turni").
2. Assicurati di aggiungere/mantenere le immagini delle icone per la PWA nella root del repository:
   - icon-180.png
   - icon-512.png
3. Esegui il commit e il push delle modifiche.
4. Su iOS (Safari): apri l'URL della webapp, fai tap sull'icona di condivisione e seleziona "Aggiungi alla schermata Home".

Note sulla sincronizzazione remota (Fase Cloud):
La presente release 4.0 opera esclusivamente in modalità offline e locale (localStorage) con sistema sicuro di migrazione automatica dalla v3.0. La sincronizzazione backend multidevice (Modalità Visualizzazione per seconda persona) potrà essere affiancata tramite integrazione API Firebase o Supabase in una fase successiva.
